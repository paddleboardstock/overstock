## The 10-Year Retention Requirement

Article 13 of Directive 2013/53/EU requires manufacturers and importers to keep the technical file and Declaration of Conformity available for **10 years** after the last unit of the product has been placed on the market. This is not a recommendation — it is a legal obligation that applies regardless of whether the product is still in production.

For RIB and inflatable boat manufacturers, this means technical documentation for every CE-marked model must remain accessible and organized for a full decade after the final sale in the EU.

## What Must Be Retained

The retained documentation must include:

- **Technical file** — design drawings, calculations, risk assessments, and test reports
- **Declaration of Conformity** — signed and dated for each model or batch
- **Production control records** — quality system documentation per the applicable module
- **EC type examination certificates** (if applicable) — certificates issued by notified bodies
- **Material and component specifications** — including adhesive systems, tube fabrics, and hull materials
- **Owner manuals** — the version supplied with each production batch

## Managing Design Changes During Retention

Design changes are inevitable over a product lifecycle. Each change requires careful documentation:

- **Minor changes** — such as a supplier substitution for an equivalent material — must be evaluated for impact on compliance and recorded in an engineering change notice
- **Significant changes** — such as hull form modifications, engine power increases, or tube volume reductions — may invalidate the original conformity assessment and require re-evaluation or re-certification

Every change must reference the original technical file version and clearly describe what was altered, why, and how compliance is maintained.

## When EC Type Examination Certificates Need Updating

Under Modules B+C and B+D, the EC type examination certificate describes the approved design. Changes that affect the essential requirements of the directive require the manufacturer to:

1. Assess whether the change falls within the scope of the existing certificate
2. Consult the notified body if the change could affect compliance
3. Obtain a certificate amendment or new certificate if required
4. Update the technical file and Declaration of Conformity accordingly

Failure to update certificates when required renders the CE mark invalid for modified units.

## Version Control Best Practices

Effective version control prevents the most common retention failures:

- **Unique file identifiers** — assign a version number to every technical file revision
- **Change logs** — maintain a master log recording every modification with date, author, and compliance impact assessment
- **Archived versions** — keep superseded versions accessible, as authorities may request documentation corresponding to units sold in a specific period
- **Digital backup** — store copies in at least two physically separate locations to protect against loss
- **Access control** — limit edit permissions while ensuring authorized personnel can retrieve files quickly during audits

## Audit Readiness

Market surveillance authorities can request the technical file at any point during the 10-year period. Manufacturers who cannot produce complete documentation within a reasonable timeframe face enforcement action. A well-organized version control system ensures that the correct documentation for any production period can be retrieved within hours.
