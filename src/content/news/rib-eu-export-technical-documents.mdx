## EU Export Requires More Than a CE Mark

Placing a RIB boat on the EU market requires a complete documentation package that satisfies the Recreational Craft Directive, supports market surveillance inquiries, and enables the importer to fulfill their legal obligations. Many manufacturers focus on obtaining the CE mark and neglect the supporting documentation system. When a market surveillance authority requests documentation — or when an importer needs to demonstrate due diligence — the absence of organized documentation creates compliance failure.

## Five-Folder Documentation Structure

Organize your EU export documentation into five logical folders:

### Folder 1: Design

The design folder contains the engineering basis for the boat:

- **GA drawings** — current revision, version-controlled
- **Hull lines and offsets** — defining the underwater form
- **Tube geometry** — profile, diameter, chamber layout, and valve positions
- **Structural calculations** — scantlings per ISO 12215 or equivalent
- **Stability and buoyancy calculations** — per ISO 12217 and ISO 6185
- **Material specifications** — hull laminate schedule, tube fabric grade, adhesive system, alloy temper
- **Design risk assessment** — systematic hazard identification and mitigation

### Folder 2: Verification

The verification folder contains test and assessment evidence:

- **Notified body type examination certificate** — the formal assessment result
- **Notified body assessment reports** — detailed test observations and findings
- **Stability test reports** — inclining test, offset load test, downflooding angle
- **Buoyancy test reports** — chamber volume verification, swamped buoyancy
- **Structural test reports** — drop test, transom load test, bond strength test
- **Material test reports** — fabric tensile/tear/adhesion, alloy mechanical properties

### Folder 3: Components

The components folder contains traceability for every significant component:

- **Tube fabric** — TDS, COA, batch numbers, supplier declarations, REACH compliance
- **Adhesive system** — product specification, cure schedule, bond strength data
- **Valves** — type approval, flow rate specifications, seal test data
- **Fuel system components** — tank, lines, fittings, filters per ISO 10088
- **Electrical components** — batteries, switch panels, wiring per ISO 10133
- **Steering system** — helm, cable/hydraulic lines, and tiller specifications
- **Navigation lights** — type approval per COLREGS and ISO 6185

### Folder 4: Delivery

The delivery folder contains documents shipped with each boat:

- **EU Declaration of Conformity (DoC)** — signed, model-specific
- **Owner manual** — per ISO 10240, in the language of the destination member state
- **Builder plate** — installed, data verified against DoC and technical file
- **CE marking** — applied per RCD requirements
- **CIN/HIN** — correctly encoded and installed per Annex II
- **Warning labels** — DANGER/WARNING/CAUTION/NOTICE per ISO 10240 and ISO 3864
- **Warranty document** — terms, claim procedure, and service contact

### Folder 5: Mass Production

The mass production folder contains ongoing production documentation:

- **Production quality plan** — inspection stations, AQL levels, acceptance criteria
- **In-process inspection records** — tube bond inspection, hull layup records, laminate cure logs
- **Final inspection checklist** — builder plate verification, CE marking placement, safety equipment check
- **Conformity verification records** — per-hull confirmation of type match
- **Material incoming inspection** — batch verification, COA review, REACH screening
- **Non-conformance records** — deviations, corrective actions, and re-inspection results
- **Surveillance audit reports** — notified body annual or biannual production audits

## RIB-Specific Sections Within Each Folder

Within these folders, RIB manufacturers must address subsystems unique to inflatable collar boats:

### Hull and Structure

- GRP laminate schedule or aluminum weld procedures
- Transom construction and engine mounting specification
- Structural bonding between hull and tube flange
- Deck and console mounting structural adequacy

### Tube and Airtightness

- Fabric specification: PVC or Hypalon, weight, coating type, and colorfastness
- Adhesive specification: two-part or contact cement, cure schedule, and environmental requirements
- Chamber pressure test: inflate to working pressure + safety margin, hold for specified duration
- Overpressure relief valve: set pressure, flow rate, and sealing verification
- Baffle valve specification: one-way isolation between chambers

### Stability, Buoyancy, and Load

- Maximum load calculation: crew + gear + provisions, excluding fixed tank fuel
- Person capacity derivation from stability and buoyancy data
- Swamped buoyancy: collar must support the boat with maximum load when fully swamped
- Inverted buoyancy: boat must not trap occupants if capsized

### Systems and Equipment

- Fuel system per ISO 10088: fixed tank, ventilation, and vapor detection where required
- Electrical system per ISO 10133: circuit protection, battery isolation, and wiring standards
- Steering system: hydraulic or cable, rated for maximum engine power
- Navigation lights: COLREGS compliance with visibility arc specifications

## The Five Must-Deliver Documents

Every EU-bound RIB must ship with these five documents physically present:

1. **EU Declaration of Conformity** — original, signed
2. **Owner Manual** — in the official language of the member state of sale, per ISO 10240
3. **Builder Plate** — permanently affixed, data matching DoC exactly
4. **CIN/HIN** — correctly encoded, permanently marked on the transom
5. **Warning Labels** — affixed in required locations per ISO 3864 and ISO 10240
