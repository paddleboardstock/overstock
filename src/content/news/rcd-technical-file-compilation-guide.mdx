## RCD Technical File: Not Optional, Not Informal

Article 7 of the Recreational Craft Directive (2013/53/EU) requires manufacturers to compile and retain a technical file demonstrating that each boat model meets the Essential Requirements of Annex I. This is not a suggestion — it is a legal obligation. The technical file must be available within 24-48 hours of a request by market surveillance authorities and retained for 10 years after the last unit is placed on the market.

## The 12-Module File Directory

A well-organized technical file follows a standardized module structure. For RIB manufacturers, each module has specific content requirements:

### Module 1: Product Identification

- Model name, variant, and serial number range
- HIN format and MIC code
- Builder plate data: design category, maximum load, maximum persons, maximum engine power
- General description of the boat type and intended use

### Module 2: Certification Boundary Definition

- Which components are included in the CE assessment (the boat, fixed installations, permanently connected equipment)
- Which components are excluded (portable equipment, user-installed accessories)
- Interface definitions for excluded items (engine mounting specifications, electrical connector standards)

### Module 3: Design and Construction Documentation

- GA drawings with revision control
- Hull lines and offsets
- Tube geometry and chamber layout
- Structural drawings: transom, stringers, bulkheads, deck
- Material specifications: hull laminate schedule, tube fabric grade, adhesive system

### Module 4: Stability and Buoyancy

- ISO 12217 compliance calculations: stability curves, angle of downflooding, offset load tests
- ISO 6185 buoyancy requirements: inflatable collar volume, chamber isolation
- Load test results: maximum load verification, person capacity verification
- Swamped buoyancy and swamped stability for applicable categories

### Module 5: Structural Integrity

- ISO 12215 scantling calculations or equivalent
- Drop test results (inflatable boats per ISO 6185)
- Transom load analysis for maximum engine weight and thrust
- Tube-to-hull joint strength testing

### Module 6: Tube and Airtightness

- Tube fabric technical data sheet (TDS): tensile strength, tear resistance, coating adhesion, UV resistance
- Adhesive system specification and bond strength test data
- Chamber pressure test results per ISO 6185
- Overpressure relief valve specification and calibration records
- Valve specification: type, flow rate, and seal integrity

### Module 7: Transom and Engine Installation

- Transom construction details and material specifications
- Engine mounting bolt pattern and torque specifications
- Maximum engine power and weight justification
- Fuel system specifications: tank, lines, fittings, and ventilation
- Electrical system specifications for engine-start circuits

### Module 8: HIN/WIN and Identification

- HIN encoding format per RCD Annex II
- MIC (Manufacturer Identification Code) registration confirmation
- HIN placement specification: location, method (engraved, molded, or bonded plate)
- WIN (Watercraft Identification Number) for engines where applicable

### Module 9: ISO Annex I Compliance Matrix

A template mapping each Essential Requirement to the supporting evidence:

| Essential Requirement | Standard Applied | Evidence Document      | Result |
| --------------------- | ---------------- | ---------------------- | ------ |
| 3.1 General           | ISO 6185         | Module 3, 4, 5         | Pass   |
| 3.2 Visibility        | ISO 11591        | Visibility test report | Pass   |
| 3.3 Stability         | ISO 12217        | Module 4               | Pass   |

Complete this matrix for all applicable requirements. Every cell must reference a specific document in the file.

### Module 10: Test Reports

- Notified body type examination report
- Internal test reports: pressure, stability, structural, drop
- Third-party test reports for materials and components
- Photographs of test setups and results

### Module 11: Risk Assessment

- Systematic hazard identification for RIB-specific risks
- Risk evaluation: severity, probability, and risk level
- Risk reduction measures implemented in design
- Residual risk documentation and user warnings

### Module 12: Declarations and Certificates

- EU Declaration of Conformity (DoC)
- Notified body certificates and assessment reports
- Quality system certificates (ISO 9001)
- Material certificates and traceability records

## RIB-Specific Focus Areas

The technical file for a RIB must address areas unique to inflatable collar boats:

- **Tube material and adhesive traceability** — every fabric roll and adhesive batch must be traceable to a specific production period and HIN range
- **Transom and engine interface** — the most common failure point in RIBs; detailed engineering justification is essential
- **HIN/WIN system** — correct encoding, placement, and registration must be documented with photographs
