## Understanding RCD Conformity Assessment Modules

The Recreational Craft Directive offers multiple conformity assessment modules that determine how a manufacturer proves compliance before affixing the CE mark. Selecting the wrong module can result in unnecessary costs, insufficient evidence, or non-compliance. The choice depends on vessel design category, length, engine exhaust, and the manufacturer's quality system maturity.

## Module A — Internal Production Control

Module A is the simplest assessment route. The manufacturer alone is responsible for ensuring compliance without involving a notified body.

- **Applicable to** — Design Category C and D boats, and certain Category A and B boats under specific conditions
- **Process** — manufacturer compiles the technical file, performs internal checks, and issues the Declaration of Conformity
- **Advantages** — lowest cost, fastest route, no third-party involvement
- **Risks** — no independent verification; non-compliance risk is entirely on the manufacturer

Module A suits established manufacturers with strong internal quality systems who produce lower-risk vessels.

## Module B+C — EC Type Examination Plus Internal Production Control

This two-part module adds independent verification:

- **Module B** — a notified body examines the technical file and a sample vessel, then issues an EC type examination certificate
- **Module C** — the manufacturer ensures each production unit conforms to the approved type through internal production control

- **Applicable to** — Design Category A and B boats, and vessels with specific engine configurations
- **Advantages** — third-party validation of the design; manageable ongoing compliance costs
- **Considerations** — requires sample vessel submission; type certificate is design-specific

## Module B+D — EC Type Examination Plus Quality Assurance

Module B+D replaces internal production control with a certified quality assurance system:

- **Module B** — same EC type examination as above
- **Module D** — the manufacturer operates an approved quality system audited by a notified body, covering production, final inspection, and testing

- **Applicable to** — same vessels as B+C, but preferred by manufacturers with ISO 9001 or equivalent quality systems
- **Advantages** — systematic quality control reduces batch-to-batch variation; recognized by large institutional buyers
- **Considerations** — requires maintaining a formal quality management system with periodic audits

## Module G — Unit Verification

Module G applies to individual vessels that are not part of a series production:

- **Process** — a notified body examines each individual vessel and its technical file, then issues a certificate of conformity for that specific unit
- **Applicable to** — one-off builds, prototypes, and custom vessels
- **Advantages** — provides compliance for unique vessels without needing a type certificate
- **Considerations** — cost per unit is highest since every vessel undergoes full assessment

## Decision Flowchart for OEM and ODM Manufacturers

Follow this logic to select the appropriate module:

1. **Is the vessel Design Category C or D with no engine exhaust or ignition protection requirements?** — Yes: Module A may suffice
2. **Is the vessel Design Category A or B?** — Module B plus either C or D is required
3. **Does the manufacturer operate a certified quality management system?** — Yes: Module B+D; No: Module B+C
4. **Is this a one-off or custom build?** — Module G

OEM manufacturers who sell under their own brand must hold the technical file and select the module. ODM factories that produce for multiple brands may need to support each brand owner's chosen module with separate documentation.

## Module Changes and Reassessment

If a manufacturer upgrades from Module A to B+D (for example, when entering new design categories), the technical file must be reassessed from scratch. Previous Module A documentation does not automatically satisfy Module B requirements.
